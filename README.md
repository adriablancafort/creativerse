# Creativerse

Creativerse is a Platform to Create, Edit, and Enhance Images and Videos with Generative AI.

<img width="1920" height="1280" alt="Creativerse platform" src="https://github.com/user-attachments/assets/9a9ae97c-7cb8-4051-a7dc-f6b756328a5b" />

## Features

### Create Image

Generate images from a text prompt. Choose from major image models, set aspect ratio, and create up to four images at a time.

### Edit Image

Upload an image and describe the changes you want. Pick a model, adjust aspect ratio and resolution when available, and iterate in a session.

### Create Video

Generate videos from a prompt, a starting frame, or both. Depending on the model, you can set end frame, duration, resolution, aspect ratio, and native audio.

### Enhance

Upscale, sharpen, and restore images or videos. Choose the enhance model and tune creative controls, scale, target resolution, and related options.

### Sessions

Each tool keeps a history of sessions so you can continue iterating on previous work. Generated assets can be handed off across tools, for example, send an image to edit, video, or enhance.

## Models & controls

Creativerse provides access to state-of-the-art image and video models.

**Image**: Seedream 5 Pro, Seedream 4.5, Nano Banana Pro, Nano Bannana 2, GPT Image 2, Grok Imagine, FLUX.2 Max, FLUX.2 Pro, FLUX.2 Flex, Recraft V4, Ideogram V4, Qwen Image 2 Pro, Krea 2

**Video**: Seedance 2.5, Seedance 2.0, MiniMax H3, Kling 3 Pro, Kling O3 Pro, Veo 3.1, FLUX.3

Available settings depend on the model and typically include:

- Aspect ratio and resolution
- Reference / source images
- Start and end frames (video)
- Duration (video)
- Audio (when supported)
- Enhance-specific controls such as scale and creativity

## Accounts & organizations

- **Accounts**: Sign up, sign in and recover your password. Manage profile, password, and account settings.
- **Organizations**: Work lives inside an organization. Create or join an org, invite members, and switch between organizations.
- **Roles & permissions**: Owner, Admin, and Member roles control who can manage the organization and who can create or only view creative work.
